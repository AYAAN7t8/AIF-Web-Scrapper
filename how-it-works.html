How it works

Four steps from page to spreadsheet

Hover the numbered dots in each screenshot for details.

Step 1

Paste a URL

Enter any public page. Sieve fetches the HTML straight from your browser. If the site blocks that (CORS), use the demo data, paste the page's HTML, or turn on the optional local proxy.

  • Press / to jump to the URL bar
  • Status pill shows idle → fetching → success / error

Step 2

Auto-detect the data

Every table is scored by rows × average columns (header rows get a 1.2× bonus). If no table qualifies, Sieve groups sibling elements by tag and class and treats the biggest group as the rows.

  • Detected block is outlined in the page preview
  • "Try another table" cycles through alternatives

Step 3

Refine, crawl and extract

Click a header to rename it, untick a column to drop it. Crawl all pages follows "Next" links with your delay and page cap. Switch modes to pull emails, phones, images, reviews and more from the same page.

  • Preview and export update in real time
  • Progress bar and Stop button while crawling

Step 4

Export anywhere

CSV opens cleanly in Excel (UTF-8 BOM). XLSX uses SheetJS. Copy as tab-separated for pasting into any sheet, or send to Google Sheets with a one-minute Apps Script.

  • Cells that look like formulas are neutralised on export
  • Image mode downloads a ZIP of the pictures you tick
