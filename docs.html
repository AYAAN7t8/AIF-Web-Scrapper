Everything you need to scrape responsibly with Sieve.

Quick Start

  1. Open the scraper and paste a URL into the top bar (or press /).
  2. Pick a mode on the left. Auto Table is the default.
  3. Press Fetch. Rows appear in the table; the detected block is outlined in the preview.
  4. Rename headers (click them) or untick columns you don't want.
  5. Export from the inspector: CSV, XLSX, clipboard or Google Sheets.
Only scrape sites you have permission to scrape. Respect robots.txt and each site's Terms of Service. Don't collect personal data you have no lawful basis to hold.

No site handy? Click Use Demo Data. It loads a built-in virtual shop (demo://shop) that has a product table, pagination, contacts, social links, team cards, reviews, a company profile and images.

Pagination

Sieve looks for the next page in this order: <link rel="next"> / a[rel~=next], links with an "next" aria-label, pagination wrappers (the item after the active page or a .next link), then short link text such as Next, →, », siguiente, suivant.

  • Scrape Next Page appends one more page.
  • Crawl All Pages (N) keeps going with your Delay until there is no next link or Max pages is reached.
  • Every row can carry source_url and page_index columns, which appear automatically once more than one page is scraped.
  • Infinite scroll and "load more" buttons need JavaScript, so they require the optional proxy.

Bulk Scrape

Use the Bulk URLs tab in the app, or the dedicated bulk page. Paste up to 500 URLs (one per line). Each URL gets a status — pending, running, done or error — and all rows are merged into one table with a source_url column. Filter chips narrow the table by site. Failed URLs can be retried.

Requests run with limited concurrency (default 3) and a delay between them. Be kind to servers.

Export

  • CSV — UTF-8 with a BOM so Excel reads accents correctly.
  • XLSX — generated with SheetJS, file name scraped-data-<timestamp>.xlsx.
  • Copy — tab-separated, paste straight into a spreadsheet.
  • Google Sheets — either copy and paste into sheets.new, or use a webhook (below).

Exports contain only enabled columns, using your renamed headers. Cells that start with =, @ or look like +cmd are prefixed with an apostrophe to prevent spreadsheet formula injection (toggle SANITIZE_FORMULAS in js/export.js).

Google Sheets webhook

Create a new Apps Script project, paste this, then Deploy → New deployment → Web app (Execute as: Me, Access: Anyone). Paste the /exec URL in the export dialog or into GOOGLE_WEBHOOK_URL at the top of js/export.js.

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.create(data.title || "Sieve export");
  var sheet = ss.getActiveSheet();
  var rows = [data.headers].concat(data.rows);
  sheet.getRange(1, 1, rows.length, data.headers.length).setValues(rows);
  return ContentService.createTextOutput(JSON.stringify({ ok: true, url: ss.getUrl() }))
    .setMimeType(ContentService.MimeType.JSON);
}

CORS & the optional proxy

Browsers only let a page read another site's HTML if that site opts in with CORS headers. Many don't, and some pages build their content with JavaScript that a plain fetch never runs. Sieve then shows a friendly error with three ways out: demo data, Paste page HTML, or the proxy.

npm install
node proxy-server.js      # http://localhost:8787

Turn on Use local proxy in the sidebar and press Test connection. The proxy then:

  • fetches pages server-side, so CORS no longer applies;
  • renders JavaScript and scrolls to the bottom with Puppeteer (when installed);
  • checks robots.txt, limits itself to 1 request/second per domain and identifies itself with a public User-Agent;
  • binds to localhost only and refuses private-network targets.

FAQ

Does my data leave my browser?
No. Fetching, parsing, detection and exports all run locally. The proxy runs on your own machine. The only third-party requests are the fonts and the SheetJS / JSZip libraries from CDNs.
Why did Fetch fail on a big site?
Most large sites don't send CORS headers. Use the proxy, or paste the page HTML.
The table is empty or wrong.
The page may render its data with JavaScript. Try the proxy, paste rendered HTML from DevTools, or use "Try another table".
Is scraping legal?
It depends on the site's terms, the data and your jurisdiction. Get permission, respect robots.txt, rate-limit yourself, and avoid personal data without a lawful basis. This is not legal advice.
Can I log in to a site and scrape it?
Requests are sent without cookies. For pages behind a login, open the page, copy the rendered HTML and use Paste page HTML.
